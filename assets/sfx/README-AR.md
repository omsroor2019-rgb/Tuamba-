# مؤثرات CITY LIFE 3D V7

هذه مؤثرات رقمية مولدة خصيصاً للمشروع بصيغة WAV أحادية القناة، 16-bit PCM، ومعدل 22050 Hz.

- pistol.wav — إطلاق المسدس
- rifle.wav — إطلاق البندقية
- shotgun.wav — إطلاق الشوتغن
- reload.wav — إعادة تعبئة
- jump.wav — القفز
- footstep.wav — خطوات اللاعب
- melee.wav — ضربة قريبة
- impact.wav — اصطدام الطلقة
